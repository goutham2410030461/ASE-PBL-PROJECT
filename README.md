# Third Eye Care – Digital Wellness & Patient Management System

A modern, secure web platform designed for clinical patient tracking, real-time health analytics, and global medical record search. Built with a focus on data privacy, modern UI design, and robust database access control.

---

## 🌟 Key Features

- **Global Patient Search:** Search across patient records instantly using name, primary condition, or contact details.
- **Clinical Analytics & Risk Scoring:** Real-time health metrics, risk assessment indicators, and wellness summary dashboards.
- **Row Level Security (RLS):** Granular access control policies differentiating permissions between doctors, nurses, and administrative staff.
- **Patient Registration & History:** Streamlined forms to onboard new patients, update medical history, and record vital parameters.
- **Modern Responsive Interface:** Clean dark-mode aesthetics using ambient glassmorphism and real-time state management.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, Lucide Icons
- **Backend & Database:** Supabase / PostgreSQL
- **Security:** PostgreSQL Row Level Security (RLS) policies
